## Features

- **Precision Timing**: Measures hours, minutes, seconds, and milliseconds
- **Lap Functionality**: Record and display lap times
- **Modern UI**: Sleek design with neon accents
- **Dark/Light Mode**: Toggle between color themes
- **Responsive Design**: Works on all device sizes
- **Smooth Animations**: Particle background and button interactions

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations, Variables)
- JavaScript (ES6 Classes, DOM Manipulation)
- Font Awesome Icons
- Google Fonts
